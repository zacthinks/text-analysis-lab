# Linguistic implementation provenance

Selected modules in this private TeAL package were migrated from **Bag of Ideas
0.8.3.post11**, an earlier project by Zachary Lim that declared the MIT license
in its `pyproject.toml`.

The migrated code is now maintained as part of TeAL rather than as a vendored
runtime dependency. TeAL owns the public translator APIs and project/artifact
integration around these modules. The original Bag of Ideas stage/storage
orchestration is not included here.
